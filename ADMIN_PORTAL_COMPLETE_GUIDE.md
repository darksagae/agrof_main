## 🚀 HOW TO USE (STEP-BY-STEP)

### **Example 1: Post Fraud Alert**

**Step 1 - Type Trigger:**
```
YOU → WhatsApp Bot: godeye
```

**Step 2 - Bot Shows Menu:**
```
BOT → YOU:
👁️ GODEYE - NEWS CONTROL

What would you like to do?

1️⃣ 📰 Create new news/alert
2️⃣ 📋 View all active news
3️⃣ 🗑️ Delete old news
4️⃣ ✅ Mark news as resolved
5️⃣ 📊 News analytics
6️⃣ 🚫 Cancel

Reply with number (1-6)
```

**Step 3 - Select Action:**
```
YOU: 1
```

**Step 4 - Select Type:**
```
BOT:
📰 SELECT NEWS TYPE

1️⃣ ⚠️ Fraud Alert (Fake products/scams)
2️⃣ 💰 Price Update (Price changes)
3️⃣ 🦠 Disease Alert (Outbreak warnings)
4️⃣ 🌧️ Weather Advisory
5️⃣ 📚 Research Update
6️⃣ 📰 General News

Reply with number
```

**Step 5:**
```
YOU: 1
```

**Step 6 - Select Priority:**
```
BOT:
🎯 SELECT PRIORITY

1️⃣ 🔴 URGENT (Immediate action needed)
2️⃣ 🟠 HIGH (Important)
3️⃣ 🟡 MEDIUM (Normal)
4️⃣ 🟢 LOW (Informational)

Reply with number
```

**Step 7:**
```
YOU: 1
```

**Step 8 - Enter Title:**
```
BOT:
📝 ENTER TITLE

Provide a clear, concise title:
▶ (Send the title)
```

**Step 9:**
```
YOU: Fake DAP Fertilizer in Kampala
```

**Step 10 - Enter Message:**
```
BOT:
📝 ENTER MESSAGE

Provide the full message/description:
▶ (Send the detailed message)
```

**Step 11:**
```
YOU: Ministry of Agriculture warns farmers about counterfeit DAP fertilizer circulating in Kampala markets. Check for authentic YARA or Dangote seals. Buy only from registered dealers like AGROF.
```

**Step 12 - Select Location:**
```
BOT:
📍 SELECT LOCATION

Where does this apply?

1️⃣ 🇺🇬 National (All Uganda)
2️⃣ 📍 Central Region
3️⃣ 📍 Eastern Region
4️⃣ 📍 Western Region
5️⃣ 📍 Northern Region

Reply with number
```

**Step 13:**
```
YOU: 2
```

**Step 14 - Confirmation:**
```
BOT:
✅ CONFIRMATION

Type: fraud
Priority: urgent
Location: Central

Title:
"Fake DAP Fertilizer in Kampala"

Message:
"Ministry of Agriculture warns farmers..."

This will be sent to ALL farmers in Central Region!

Reply YES to publish or NO to cancel
```

**Step 15:**
```
YOU: YES
```

**Step 16 - Published!:**
```
BOT:
✅ NEWS PUBLISHED!

⚠️ Fake DAP Fertilizer in Kampala

ID: #6
Type: fraud
Priority: urgent
Location: Central

📱 Visible to all farmers immediately!

To manage: Type godeye again
```

**DONE!** All farmers now see this alert in their app! 📱✨
